# speclet implement

Implement all tasks in a single phase, marking each done as you go.

Phase (required): $ARGUMENTS

1. Read `.speclet/context.md` and `.speclet/constitution.md` (if present and filled in).
2. Read `.speclet/tasks/index.md` to find the phase file.
3. Resolve the phase from $ARGUMENTS by number or name.
4. Load ONLY that phase file — do not load any other phase files.
5. Work through each unchecked task `- [ ]` in order: implement it, then mark it `- [x]`.
6. Follow the instructions in `.speclet/prompts/implement.md`.
