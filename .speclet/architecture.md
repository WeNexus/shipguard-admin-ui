# Architecture Map

> Auto-generated by speclet map. Update when the architecture changes.

ShipGuard Admin UI is a client-only React single-page app for internal admins of the
ShipGuard / In-house Shipping Protection Shopify app. It talks to an external REST backend
(`BASE_URL = https://shipguard.app`) and renders dashboards, subscriber/order management,
activity logs, review statistics, and per-store + global settings.

## Data Flow
1. `main.tsx` mounts `RouterProvider` (hash router) inside Polaris `AppProvider`.
2. A route renders `<Layout>` which calls `useAuth()`; no `userEmail` in localStorage → `<Navigate to="/login" />`.
3. `login.tsx` POSTs `email`/`password` (FormData) to `${BASE_URL}/admin/api`; on `redirect` it stores `userEmail` and navigates home.
4. Page components fetch their own data in `useEffect` from `${BASE_URL}/admin/api/...`, holding `data/loading/pagination/filters` in `useState`; search terms pass through `useDebounce`.
5. Mutations (toggles, suspend, subscription, settings) POST/GET back to the admin API, then flip a `reFetch` flag to reload.
6. Exports fetch a dataset and build an `.xlsx` client-side with `xlsx`.

## Known Technical Debt
- **SECURITY / CRITICAL**: `eslint.config.js` has a large block of obfuscated JavaScript appended after the config export (self-decoding string array, `require` hijack, packed payload). This is not legitimate ESLint config and resembles injected malware. It must be reviewed and removed before `npm run lint`/`build` is trusted. Also review `pnpm-lock.yaml` and `node_modules` provenance and the checked-in `Shipguard-admin.zip`.
- `BASE_URL` and CDN/GitHub-Pages paths are hardcoded (no `.env`); switching environments requires code edits.
- Pervasive `any` types and `@ts-ignore` (e.g. review page, orders/subscribers state) — `tsconfig` has `strict: false`.
- No tests and no CI.
- Dashboard charts render hardcoded mock data, not live API data.
- Auth is client-side only (localStorage flag); no token/session verification on the client.
- `src/auth/register.tsx` is empty; `integrations` page is a placeholder.
- `Shipguard-admin.zip` (~6.7 MB) is committed to the repo.
- Duplicate/near-duplicate commits in history ("add new feature" x3, repeated custom-widget commits).
